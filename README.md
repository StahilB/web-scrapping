# Web-scrapping

Скрипт ищет статьи на Хабре по ключевым словам и выводит дату, заголовок и ссылку.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Ключевые слова задаются в списке `KEYWORDS` в начале файла `main.py`. Поиск не зависит от регистра букв.

По умолчанию проверяется текст превью статьи на странице `https://habr.com/ru/all/`.

Чтобы дополнительно искать по полному тексту статей, измените настройку:

```python
SEARCH_FULL_TEXT = True
```

В этом режиме программа открывает страницу статьи, если ключевые слова не найдены в превью.

Результат выводится в формате:

```text
2026-10-10 – Название статьи – https://habr.com/ru/articles/123456/
```
